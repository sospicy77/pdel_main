INPUT DATA

Weather (daily)
🌡Temperature (°C)
💧Relative Humidity (%)
☔Rainfall (mm)
≈Wind Speed (m/s)

1. MULTIPLICATION

Bacterial population (N)

Discrete logistic growth
Ns = Ns−1 + rs Ns−1(1 − Ns−1)
start from N0, apply rt−K … rt  →  Nt
rt = μmax × fT(T) × fRH(RH)
fRH(RH) = 11 + exp[−kM(RH − RHth,M)]
fT(T): cardinal temperature function
RHth,M: RH threshold for growth (50%)
kM: logistic slope (kM = 0.3)
K: growth period (3 days)
N ∈ [0, 1]
×

2. DISPERSAL

Dispersal potential (D)

Weather-driven dispersal
Dweather = 1 − exp(−Etotal)
where,
Etotal = arain × Rain
        + awind × Wind
        + aint × (Rain × Wind)
Insect pathway (optional)
Dinsect = insect_coeff
D = 1 − (1 − Dweather)(1 − Dinsect)
No aboveground dispersal
if use_dispersal = FALSE  →  D = 1
D ∈ [0, 1]
×

3. INFECTION

Infection conditions (I)

Humidity / rainfall (wetness) response
• if Rain ≥ Rainth
W(RH, Rain) = 1
• if Rain < Rainth
W(RH, Rain) = 11 + exp[−kI(RH − RHth,I)]
Rainth: rainfall threshold (0.25 mm/day)
RHth,I: RH threshold for infection (90%)
kI: logistic slope (kI = 1)
━ Rain < Rainth    ┄ Rain ≥ Rainth
I = W(RH, Rain)
I ∈ [0, 1]

4. RISK

Daily infection risk (Risk)

Risk = N × D × I
if use_dispersal = FALSE
(D = 1) → Risk = N × I
Example: fire blight, ID101 (2019)
Risk ∈ [0, 1]

OUTPUT

Daily indices
• Daily Risk
• N (population)
• D (dispersal)
• I (infection)
